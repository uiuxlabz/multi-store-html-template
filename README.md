# Mercato — Multi-Brand Fashion Marketplace Template

**Curated style, one marketplace.**

A premium, framework-free multi-brand fashion marketplace template built with semantic HTML5, custom CSS design system, and vanilla JavaScript. Designed for online boutiques, multi-vendor marketplaces, and fashion retailers.

## Features

- **Framework-free** — pure HTML5, CSS3 (custom properties, Grid, Flexbox, `clamp()`), vanilla JavaScript
- **Premium fashion aesthetic** — black + ivory + terracotta palette, Bodoni Moda display headlines
- **Fluid responsive** — three breakpoints, no horizontal scroll on any viewport
- **Hero carousel** — 3-slide crossfade with text overlay (IntersectionObserver-powered)
- **Scroll reveal** — `.reveal` animations (respects `prefers-reduced-motion`)
- **Mobile nav** — burger toggle with `aria-expanded` accessible pattern
- **Product grid** — hover actions, sale badges, sold-out states, star ratings
- **Offer banners** — full-width image overlays with CTA buttons
- **Vendor strip** — brand logo grid with hover effects
- **Testimonial cards** — shopper quotes with avatars and star ratings
- **Cart & checkout** — table layout, quantity controls, summary sidebar, form validation
- **Contact form** — validation feedback, `[data-form]` hook, success/error states
- **Original imagery** — product photography, no placeholders

## Tech Stack

- HTML5 + CSS3 (W3C-valid, semantic landmarks)
- Vanilla JavaScript (canonical IIFE build)
- Google Fonts (Bodoni Moda + Inter)
- SVG favicon (inline data: URI)
- OpenStreetMap embed (contact page)

## SEO

- Semantic HTML5 structure (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
- Unique `<title>` and `<meta description>` per page
- `lang="en"` attribute, `charset="utf-8"`, viewport meta
- Alt text on all images
